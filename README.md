# HR_Attrition_Report
Project Overview
The HR Attrition Dashboard is an interactive Power BI dashboard designed to analyze employees. 
The dashboard provides insights into attrition trends across departments, job roles, age groups, gender, income levels, and other employee-related factors. Prepared 2 pages dashboard by using Overview page - it show overall overview of report is about and Deep Dive shows deep information about the company.

**This project uses Microsoft Fabric**
The process includes:
Ingesting the HR dataset into Microsoft Fabric
Storing data in a Fabric Lakehouse
Using Dataflow Gen2 for data preparation
Cleaning and transforming employee data
Connecting the prepared data to Power BI
Building the HR Attrition Dashboard

**Business Objective**
The objective of this project is to help HR teams:
- Monitor employee attrition
- Identify employee groups with higher attrition
- Analyze attrition across departments and job roles
- Support data-driven HR workforce decisions

  **Tools & Technologies**
- Microsoft Fabric
- Power BI
- Power Query
- DAX
- Data Visualization
- HR Analytics

**The dataset contains employee-level HR information, including:**
- Employee demographics
- Attrition Rate
- Department
- Job role
- Monthly income
- Job satisfaction
- Years at company
- Overtime
- Attrition status
- Gender
  
**Key Business Questions**
The dashboard answers questions such as
What is the overall employee attrition rate?
Which departments have higher attrition?
Which job roles experience greater employee attrition?
Which age groups have higher attrition?
Is overtime associated with employee attrition?
